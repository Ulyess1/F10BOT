Privacy Policy for BROADCAST

Last Updated: December 6, 2025

1. Introduction

This Privacy Policy explains how the Discord bot BROADCAST (“the Bot”) handles data when used in a Discord server. BROADCAST is developed to send messages to server members and listen to commands or tokens provided by users or administrators. We respect user privacy and aim to be transparent about how the Bot processes information.

2. Data Collection

BROADCAST does not collect, store, log, or save any personal data outside of Discord.

The Bot may temporarily process certain Discord data only while executing commands, such as:

  • User IDs
  • Server IDs
  • Channels
  • Messages or tokens used to trigger bot functions

This data is processed in real-time only and is never saved to databases, logs, files, or external servers.

3. How the Bot Uses Data

Any data processed by BROADCAST is used only to perform its core functions, including:

  • Sending messages or announcements to server members
  • Responding to triggers, tokens, or commands
  • Ensuring the bot can execute admin or broadcast operations inside the server

The Bot does not:

  • Track users
  • Analyze user behavior
  • Sell or share any information
  • Store data for future use

4. Data Storage

BROADCAST does not store any information. All data is handled temporarily and automatically discarded immediately after the command completes.

5. Third Parties

BROADCAST does not send data to third parties. All bot activity occurs inside Discord using Discord’s API.

6. Children’s Privacy

BROADCAST does not target or collect data from children. As the bot does not store any data, it is compliant with general privacy requirements.

7. Your Rights

Since BROADCAST does not store data, there is no data to view, modify, or delete. However, you may always remove the bot from your server if you wish to stop its functionality.

8. Updates to This Policy

We may update this Privacy Policy from time to time. The latest version will always be available at the published link.

9. Contact Information

If you have questions about this Privacy Policy or how BROADCAST works, you can contact the developer at: icloudhelp10@gmail.com
